# Causa Do 401

Emissor: `POST /api/v1/browser/view-token`.

Validador configurado antes: `GET /api/desktop-browser/validate-view-token`.

Storage emissor: PostgreSQL, tabela `desktop_view_tokens`, digest SHA-256, purpose `desktop_browser_view`.

Storage validador legado: mesmo helper `validate_token`, tambem PostgreSQL, mas inacessivel ao subrequest por middleware.

Diferenca critica: o emissor v1 exige usuario CotaSync autenticado para emitir o token. A validacao do Nginx precisa autenticar apenas o token desktop recebido em header, sem cookie da sessao principal. O endpoint legado nao estava liberado para esse fluxo interno.

Por que retornava 401: `auth_request /_desktop_view_auth` chamava o backend sem `cotasync_session`; o middleware retornava `401 Authentication required`; o Nginx convertia isso na pagina `401 Authorization Required` dentro do iframe.

Correcao: novo endpoint v1 tecnico `GET /api/v1/browser/validate-view-token`, publico no middleware apenas por path e protegido pela validacao do token desktop. Nginx passou a chamar esse endpoint.
